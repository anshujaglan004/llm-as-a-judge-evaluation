# LLM-as-a-Judge Evaluation Pipeline

## Project Overview

This project implements an LLM-as-a-Judge evaluation pipeline for
systematically evaluating answers generated by language models.

Google Gemini is used as the LLM judge. The system evaluates candidate
answers using a structured rubric and produces criterion-level scores,
an overall score, and a written rationale.

The project also includes tests for common evaluation biases and
reliability issues.

## Main Features

- Pointwise LLM evaluation
- Reference-based evaluation
- Pairwise A-vs-B comparison
- Position-bias testing
- Length / verbosity bias testing
- Self-preference testing
- Consistency testing
- Adversarial testing
- Structured JSON verdicts
- CSV evaluation summary
- Secure Gemini API-key handling

## Evaluation Rubric

The evaluation uses five criteria:

| Criterion | Weight |
|---|---:|
| Correctness | 25% |
| Faithfulness | 20% |
| Completeness | 20% |
| Instruction-following | 20% |
| Tone / Safety | 15% |

Each criterion is scored from 0 to 10.
